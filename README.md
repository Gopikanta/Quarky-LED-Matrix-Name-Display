

# Quarky LED Matrix – My Name Display Using PictoBlox

## Project Overview

This project demonstrates how to use the **Quarky Robotics Board** with **PictoBlox** to display text, individual letters and patterns on an LED matrix.

The program initially displays the name **GOPIKA** and then displays each letter individually in different colours with a one-second delay. Finally, a heart pattern appears on the LED matrix.

## Objectives

- Learn LED matrix programming using Quarky.
- Understand block-based programming with PictoBlox.
- Display text and individual letters on an LED matrix.
- Explore different LED display colours.
- Use timing blocks to control the sequence of outputs.
- Create a heart pattern using the LED matrix.

## Program Logic

The program follows these steps:

1. **Start:** Execute the program when the green flag is clicked.
2. **Display Name:** Show the complete name GOPIKA on the LED matrix.
3. **Display G:** Show G in red.
4. **Wait:** Pause for one second.
5. **Display O:** Show O in yellow.
6. **Wait:** Pause for one second.
7. **Display P:** Show P in cyan.
8. **Wait:** Pause for one second.
9. **Display I:** Show I in blue.
10. **Wait:** Pause for one second.
11. **Display K:** Show K in pink.
12. **Wait:** Pause for one second.
13. **Display A:** Show A in red.
14. **Final Output:** Display a heart pattern on the LED matrix.

## Colour Sequence

| Letter | Display Colour |
|---|---|
| G | Red |
| O | Yellow |
| P | Cyan |
| I | Blue |
| K | Pink |

## PictoBlox Programming Blocks

The following blocks are used:

- When Green Flag Clicked
- Display Text
- Display Letter with Colour
- Wait (1 second)
- Display Matrix

## Expected Output

When the program runs, Quarky's LED matrix displays:

1. The complete name GOPIKA.
2. Individual letters G, O, P, I, K and A, one after another.
3. A heart pattern at the end.

## Learning Outcomes

By completing this project, students will learn:

- How to connect and program Quarky using PictoBlox.
- How to control an LED matrix through programming.
- How to display letters using different colours.
- How to use delays to control program execution.
- How to create simple visual patterns using LED matrices.

## Conclusion

This project provides a beginner-friendly introduction to robotics and block-based programming. It demonstrates how Quarky and PictoBlox can be used to create colourful text displays and simple LED matrix animations.
